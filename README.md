# 📁 React Projects Showcase

A React-based web application that allows users to explore and filter different projects based on categories like Static, Responsive, and Dynamic.

---

## 🚀 Features

* 📌 Tab-based navigation for project categories
* 🔍 Dynamic filtering of projects
* 🧩 Reusable React components
* ⚡ Fast and responsive UI
* 📱 Clean and user-friendly design

---

## 🛠️ Tech Stack

* React JS (Class Components)
* JavaScript (ES6+)
* CSS3

---

## 📂 Project Structure

```
src/
 ├── components/
 │   ├── Header/
 │   ├── TabItem/
 │   ├── ProjectItem/
 ├── App.js
 ├── App.css
```

## ▶️ Getting Started

### 1. Live demo

```bash
https://keerthanaui5cqrjsivsfcbc.drops.nxtwave.tech/
```

### 2. Navigate to project folder

```bash
cd projects-filter-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the app

```bash
npm start
```
